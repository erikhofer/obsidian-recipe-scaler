# Recipe Scaler — Example Vault

This vault demonstrates the Recipe Scaler plugin.

## Setup

1. From the repo root, run `npm run build:install` to build the plugin and copy it into this vault.
2. Open this folder as a vault in Obsidian.
3. Enable the **Recipe Scaler** plugin under Settings → Community plugins.
4. In Settings → Recipe Scaler, add these plural pairs to see pluralization work:
   - `cup` / `cups`
   - `tablespoon` / `tablespoons`
   - `teaspoon` / `teaspoons`
   - `clove` / `cloves`
   - `pinch` / `pinches`

## Examples

- **Single note:** `Recipes/Pizza Marinara.md`
- **Canvas:** `Recipes/Three-Course Dinner.canvas` (added in a later task)

Switch the note to Reading View (Ctrl/Cmd+E) to see the scaler UI.
